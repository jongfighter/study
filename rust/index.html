    GET STARTED

    시작하기 전에

    아래 네 가지만 확인하면 바로 레슨 00을 시작할 수 있습니다.

    01

    Rust 설치 확인

    터미널에서 rustc --version과 cargo --version을 실행해 버전이 출력되면 준비된 것입니다. VS Code 기본 터미널이 bash(MSYS2)라면 레슨 01에서 PowerShell 프로필로 터미널을 여는 방법을 먼저 확인하세요.

    02

    코스 폴더를 VS Code로 열기

    VS Code에서 파일 → 폴더 열기로 D:\study\rust 폴더 전체를 엽니다. 파일만 열면 이 코스의 .vscode 설정이 적용되지 않습니다. 자세한 방법은 레슨 00에 있습니다.

    03

    문서와 VS Code를 나란히 두기

    이 문서는 Chrome이나 Edge로 열고, 화면을 반으로 나눠 한쪽에는 문서를, 다른 쪽에는 VS Code를 둡니다. 읽고, 입력하고, 실행하는 흐름이 가장 편합니다.

    04

    진도 저장 확인

    체크한 진도는 브라우저에 저장됩니다. 레슨 페이지에서 체크한 뒤 이 페이지로 돌아와 진행률이 바뀌는지 확인하세요. 바뀌지 않으면 Chrome이나 Edge로 열어 보세요.
