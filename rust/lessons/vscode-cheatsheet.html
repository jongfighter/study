    VS Code 단축키·설정 치트시트

    Rust 실전 입문 코스에서 쓰는 VS Code 단축키, 설정 키, 명령 팔레트 이름을 분류별로 모았습니다. 모든 단축키는 Windows 기본값이며, VS Code 1.146 기준으로 공식 문서와 설치된 VS Code로 확인했습니다.

    • 기준 Windows · VS Code 1.146
    • 단축키 수 108개
    • 코스 홈 Rust 실전 입문 홈
    • 처음이라면 레슨 00 · VS Code 첫걸음

    GUIDE이 표를 읽는 법

    • 단축키 안의 +는 키를 동시에 누른다는 뜻입니다(예: Ctrl+Shift+P는 Ctrl과 Shift를 누른 채 P).
    • 공백으로 이어진 조합은 차례로 입력합니다(예: Ctrl+K Ctrl+S는 Ctrl+K를 누른 뒤 이어서 Ctrl+S). 공식 문서에서는 이를 chord(코드)라고 부릅니다.
    • 공식 명령 이름은 명령 팔레트(Ctrl+Shift+P)에서 검색하는 이름입니다. 단축키가 먹지 않거나 키보드 배열 때문에 누르기 어렵다면 이 이름을 입력해 실행하세요. 백틱(`) 키가 없는 키보드도 같은 방법으로 해결됩니다.
    • 레슨 열은 이 단축키를 처음 자세히 다루는 레슨 번호입니다. 다른 레슨에서도 쓸 수 있습니다. —는 특정 레슨에서 따로 다루지 않는 참고용 단축키입니다.
    • 표시되는 단축키는 현재 키보드 배열 기준이고, 내가 바꾼 단축키는 기본값과 다를 수 있습니다. 단축키 편집기(Ctrl+K Ctrl+S)의 더 보기(...) 메뉴에서 Show User Keybindings를 고르면 내가 바꾼 것만 모아 볼 수 있습니다.

    SETTINGS설정 키 표

    설정 화면(Ctrl+,)의 검색창에 설정 키를 입력하면 바로 찾을 수 있습니다. 이 코스 폴더의 .vscode/settings.json에 이미 들어 있는 설정은 "이 폴더는 ..."으로 표시했습니다. 값을 바꾸면 settings.json에 기록되고, Reset Setting으로 되돌릴 수 있습니다.

    설정 키값의미레슨
    files.autoSaveoff (기본), afterDelay, onFocusChange, onWindowChange파일을 자동으로 저장하는 시점. afterDelay이면 저장 시 서식 정리는 직접 저장할 때만 동작합니다.00

    NOTEWindows에서 알아 둘 주의사항

    그래픽 드라이버와 단축키 충돌공식 문서는 "그래픽 카드 드라이버(예: NVIDIA)가 이 기본 단축키(위·아래에 커서 추가)를 덮어쓸 수 있다"고 안내합니다. Intel 그래픽 제어판이 Ctrl+Alt+↑·Ctrl+Alt+↓를 화면 회전 단축키로 가로채 VS Code에서 동작하지 않았다는 사용자 보고도 있습니다(VS Code 저장소 이슈 #106089). 그래픽 드라이버의 단축키를 끄거나, 단축키 편집기에서 다른 키로 바꾸세요.
    • 터미널 분할 Ctrl+Shift+5는 터미널에 포커스가 있을 때만 동작합니다. 에디터에서 누르면 아무 일도 일어나지 않는 것이 정상입니다.
    • 테스트 단축키 Ctrl+; F, Ctrl+; C는 에디터에 포커스가 있을 때만 동작하고, Ctrl+; A는 어디서든 동작합니다.
    • 탭 닫기: Windows에서는 Ctrl+F4와 Ctrl+W가 모두 탭 닫기입니다. 공식 키 표에는 Ctrl+F4 쪽만 보이므로, Ctrl+W는 설치된 VS Code로 직접 확인했습니다.
    • 폴더 열기 Ctrl+K Ctrl+O는 공식 키 표에 없습니다. 설치된 VS Code 1.146에서 Windows·Linux 기본값으로 확인했습니다. macOS에서는 Cmd+O가 파일·폴더 열기입니다.
    • 다음 문제로 이동 F8은 문제가 있는 모든 파일을 차례로 돕니다. 현재 파일 안에서만 돌려면 Alt+F8을 씁니다.
    • 키보드 배열: 공식 문서에 따르면 단축키는 현재 키보드 배열에 맞게 표시됩니다. 한국어 키보드에서 백틱·대괄호 같은 기호 키 조합이 다르게 보이면 단축키 편집기에 보이는 표기를 기준으로 삼으세요.
    • 제한 모드(Restricted Mode)에서는 터미널, 작업, 디버깅, 확장 기능이 막혀 있어 일부 단축키가 동작하지 않을 수 있습니다. 상태 표시줄에 제한 모드 배지가 있는지 먼저 확인하세요.
