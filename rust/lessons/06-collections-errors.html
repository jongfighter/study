    핵심 개념 한국어 요약

    컬렉션(collection)은 힙에 저장되어 실행 중에 크기가 변하는 자료구조입니다. Vec<T>는 같은 타입 값의 가변 길이 목록이며, vec![1, 2, 3] 매크로로 만듭니다. v[i]는 범위를 벗어나면 패닉(panic)으로 프로그램을 멈추고, v.get(i)는 Option을 돌려줘 없는 경우를 값으로 다룹니다. for x in &v는 읽기로, for x in &mut v는 수정하며 순회합니다(레슨 04의 빌림 규칙이 그대로 적용됩니다).

    Rust에는 문자열 타입이 두 가지입니다. String은 힙에 있고 내가 소유하며 늘릴 수 있는 문자열, &str은 어딘가의 문자열 일부를 빌려 보는 읽기 전용 슬라이스입니다. 문자열 리터럴 "hello"의 타입이 &str입니다. 모든 문자열은 UTF-8이라서 한국어 글자 하나가 3바이트입니다. len()은 바이트 수이고 글자 수는 chars().count()입니다. 그래서 s[0] 같은 정수 인덱싱은 아예 막혀 있고, 범위 슬라이스는 글자 경계에 맞지 않으면 패닉이 납니다. HashMap<K, V>는 키로 값을 찾는 해시 테이블입니다. 반복 순서가 정해져 있지 않다고 책이 설명하므로, 출력할 때는 정렬해서 쓰는 습관이 필요합니다. entry(키).or_insert(기본값)은 "없으면 넣고, 값에 대한 가변 참조를 돌려준다"는 단어 세기의 관용구입니다.

    Rust에는 예외(exception)가 없습니다. 실패할 수 있는 함수는 Result<T, E>(Ok(값) 또는 Err(오류))를 돌려줍니다. 호출하는 쪽은 match로 처리하거나, 함수 안에서 ? 연산자를 써서 "Err이면 그 오류를 그대로 호출자에게 반환"하게 합니다. ?는 오류 타입이 다를 때 From trait의 from으로 변환해 주므로, 오류 enum에 impl From<ParseIntError>를 만들어 두면 숫자 파싱 오류가 자동으로 내 오류 타입으로 바뀝니다. panic!은 "있어서는 안 되는 버그"에 쓰고, 예상 가능한 실패(잘못된 입력, 없는 파일)는 Result로 돌려주는 것이 기본 방침입니다.

    5. 사용자 정의 오류 타입과 ? 입력하기

      (4단계와 별개) 이 단계의 코드가 이 레슨의 핵심입니다. my_errors.rs를 만들어 입력합니다. 한 줄 문자열 "1, 우유 사기, false"를 Task로 바꾸는 parse_task가 4가지 실패(필드 개수, id, 제목, done 값)를 구분해서 돌려줍니다.

      use std::error::Error;
use std::fmt;
use std::num::ParseIntError;

#[derive(Debug, PartialEq)]
struct Task {
    id: u32,
    title: String,
    done: bool,
}

#[derive(Debug, PartialEq)]
enum ParseTaskError {
    WrongFieldCount(usize),
    InvalidId(ParseIntError),
    EmptyTitle,
    InvalidDone(String),
}

impl fmt::Display for ParseTaskError {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        match self {
            ParseTaskError::WrongFieldCount(n) => {
                write!(f, "필드는 3개여야 하는데 {n}개입니다")
            }
            ParseTaskError::InvalidId(e) => write!(f, "id가 숫자가 아닙니다: {e}"),
            ParseTaskError::EmptyTitle => write!(f, "제목이 비어 있습니다"),
            ParseTaskError::InvalidDone(text) => {
                write!(f, "done은 true/false여야 하는데 '{text}'입니다")
            }
        }
    }
}

impl Error for ParseTaskError {}

impl From<ParseIntError> for ParseTaskError {
    fn from(e: ParseIntError) -> ParseTaskError {
        ParseTaskError::InvalidId(e)
    }
}

fn parse_task(line: &str) -> Result<Task, ParseTaskError> {
    let fields: Vec<&str> = line.split(',').collect();
    if fields.len() != 3 {
        return Err(ParseTaskError::WrongFieldCount(fields.len()));
    }

    let id = fields[0].trim().parse::<u32>()?;
    let title = fields[1].trim();
    if title.is_empty() {
        return Err(ParseTaskError::EmptyTitle);
    }
    let done = match fields[2].trim() {
        "true" => true,
        "false" => false,
        other => return Err(ParseTaskError::InvalidDone(other.to_string())),
    };

    Ok(Task {
        id,
        title: title.to_string(),
        done,
    })
}

fn parse_all(text: &str) -> Result<Vec<Task>, ParseTaskError> {
    let mut tasks = Vec::new();
    for line in text.lines() {
        if line.trim().is_empty() {
            continue;
        }
        tasks.push(parse_task(line)?);
    }
    Ok(tasks)
}

fn main() -> Result<(), Box<dyn Error>> {
    let input = "1, 우유 사기, false\n2, 보고서 쓰기, true\n";
    let tasks = parse_all(input)?;
    for task in &tasks {
        println!("{task:?}");
    }

    for bad in ["x, 제목, false", "1, , false", "1, 제목", "1, 제목, maybe"] {
        match parse_task(bad) {
            Ok(task) => println!("뜻밖의 성공: {task:?}"),
            Err(e) => println!("실패한 입력 {bad:?} -> {e}"),
        }
    }

    let result = parse_all("1, 가, true\n2, 나, 3");
    println!("전체 파싱 결과: {result:?}");
    Ok(())
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn parses_valid_line() {
        let task = parse_task("5, 청소, true").unwrap();
        assert_eq!(
            task,
            Task {
                id: 5,
                title: String::from("청소"),
                done: true
            }
        );
    }

    #[test]
    fn reports_wrong_field_count() {
        assert_eq!(
            parse_task("1, 제목"),
            Err(ParseTaskError::WrongFieldCount(2))
        );
    }

    #[test]
    fn converts_parse_int_error_with_question_mark() {
        let err = parse_task("x, 제목, false").unwrap_err();
        assert!(matches!(err, ParseTaskError::InvalidId(_)));
    }

    #[test]
    fn rejects_empty_title_and_bad_done() {
        assert_eq!(parse_task("1, , false"), Err(ParseTaskError::EmptyTitle));
        assert_eq!(
            parse_task("1, a, maybe"),
            Err(ParseTaskError::InvalidDone(String::from("maybe")))
        );
    }

    #[test]
    fn parse_all_stops_at_first_error() {
        assert_eq!(parse_all("1, a, true\n\n2, b, false").unwrap().len(), 2);
        assert!(parse_all("1, a, true\n2, b").is_err());
    }
}

    use std::collections::HashMap;

fn word_frequencies(text: &str) -> Vec<(String, usize)> {
    let mut counts: HashMap<String, usize> = HashMap::new();
    for word in text.split_whitespace() {
        *counts.entry(word.to_lowercase()).or_insert(0) += 1;
    }

    let mut result: Vec<(String, usize)> = counts.into_iter().collect();
    result.sort_by(|a, b| b.1.cmp(&a.1).then(a.0.cmp(&b.0)));
    result
}

    use std::num::ParseIntError;

fn parse_sum(input: &str) -> Result<i64, ParseIntError> {
    let mut total = 0;
    for piece in input.split(',') {
        let number: i64 = piece.trim().parse()?;
        total += number;
    }
    Ok(total)
}

fn main() {

            Err(e) => println!("{input:?} 은(는) 계산할 수 없습니다: {e}"),

    }
