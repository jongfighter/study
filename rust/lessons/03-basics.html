    핵심 개념 한국어 요약

    변수는 기본이 불변입니다. let x = 5;로 만든 변수에 다시 값을 넣으면 컴파일 오류이고, 바꾸려면 let mut x라고 명시해야 합니다. 값이 바뀔 수 있는 곳이 눈에 보이게 하려는 설계입니다. 섀도잉(shadowing)은 같은 이름으로 let을 다시 쓰는 것이며, 새 변수를 만들기 때문에 타입이 바뀌어도 됩니다. 상수(constant)는 const로 선언하고 타입을 반드시 적으며 이름은 관례적으로 대문자와 밑줄을 씁니다.

    Rust는 정적 타입 언어이지만 대부분 타입을 추론합니다. 정수의 기본은 i32, 소수의 기본은 f64입니다. 정수 타입 이름은 부호(i는 부호 있음, u는 부호 없음)와 비트 수로 정해집니다. usize는 컬렉션의 길이와 인덱스에 쓰는 타입입니다. 서로 다른 정수 타입끼리는 자동 변환되지 않아서 as나 From으로 직접 바꿔야 합니다. 튜플(tuple)은 서로 다른 타입을 묶는 고정 길이 값이고, 배열(array)은 같은 타입의 고정 길이 값입니다.

    Rust는 표현식 중심 언어입니다. if, match, 블록 { ... }이 모두 값을 가질 수 있고, 블록의 값은 마지막 식입니다. 문장(statement)은 값을 만들지 않으며, 식 뒤에 세미콜론을 붙이면 그 식은 문장이 되어 값이 버려집니다. 함수 끝에 a + b라고 쓰면 그 값이 반환되고, a + b;라고 쓰면 반환하지 않는 함수가 됩니다. 이 차이가 가장 흔한 초보 오류의 원인입니다.

    for (index, fruit) in fruits.iter().enumerate() {

    }
}

fn classify(n: i32) -> String {
    if n < 0 {

    }
    if n == 0 {
        String::from("영")
    } else {
        String::from("양수")

}

      인레이 힌트(inlay hints)는 코드 줄 사이에 흐리게 끼워 보여 주는 추론 정보입니다. 먼저 my_variables.rs에서 let spaces = spaces.len(); 줄을 보면 변수 이름 뒤에 회색 : usize가 붙어 있습니다. 실제 입력한 글자가 아니라 rust-analyzer가 추론한 타입입니다. Ctrl+,로 설정을 열고 editor.inlayHints.enabled를 검색해 작업 영역 탭에서 값을 off로 바꿉니다. 회색 글씨가 모두 사라집니다. .vscode/settings.json에는 "editor.inlayHints.enabled": "off"로 기록됩니다. 선택 가능한 값은 on, off, onUnlessPressed, offUnlessPressed입니다. offUnlessPressed는 평소에는 숨기고 Ctrl+Alt를 누르는 동안만 보여 줍니다. 값을 확인하고 on으로 되돌립니다.

      Rust만 골라서 종류별로 끄는 설정도 있습니다. rust-analyzer.inlayHints.typeHints.enable(변수 타입 힌트)과 rust-analyzer.inlayHints.parameterHints.enable(호출할 때 매개변수 이름 힌트)가 대표적입니다. 타입 힌트는 읽기에 도움이 되지만, 힌트가 코드의 일부라고 착각하지 않도록 처음 한동안은 켜 둔 채 "내가 쓴 글자인가?"를 확인하는 습관을 권합니다.

    정답 예시 보기 
    fn collatz_steps(start: u64) -> u32 {
    let mut n = start;
    let mut steps = 0;
    while n != 1 {
        if n.is_multiple_of(2) {
            n /= 2;
        } else {
            n = 3 * n + 1;
        }
        steps += 1;
    }
    steps
}

fn main() {

        println!("{start}에서 1까지 {}단계", collatz_steps(start));
    }
}
