    핵심 개념 한국어 요약

    캡스톤(capstone)은 배운 것을 한 프로젝트에 모아 스스로 확장하는 마무리 과제입니다. 이 코스의 캡스톤은 레슨 11의 Task API를 출발점으로 삼습니다. 원본(lesson11)은 레슨 설명과 1:1로 맞춰 둔 기준 코드이므로 건드리지 않고, 폴더를 복사한 capstone에서 작업합니다. 확장 과제는 네 갈래입니다. (A) 목록에 done 필터와 limit·offset(쿼리 파라미터), (B) 저장소 추상화(TaskRepository trait), (C) 영속화(파일에 저장), (D) 운영 습관(요청 로그, 종료 처리, Query 에러의 JSON 통일).

    이 레슨의 lab/lesson12는 axum 없이 표준 라이브러리만으로 만든 "도구 상자" 크레이트입니다. 쿼리 문자열 해석과 필터·페이지 계산(query.rs), Task 한 줄 변환(codec.rs), 저장소 trait과 메모리 구현(repo.rs)이 들어 있고 모두 테스트가 통과합니다. 파일 저장소(FileRepository)만 todo!()로 비워 두었고 해당 테스트는 #[ignore]입니다. 미완성이어도 cargo test가 깨지지 않도록 한 것입니다.

    rustlings는 "고쳐야 컴파일되는 작은 연습 코드"를 한 문제씩 푸는 공식 연습 도구입니다. 클론해 둔 rustlings 폴더는 도구의 소스 저장소이고, 직접 푸는 연습 폴더는 rustlings init이 별도로 만듭니다. 이 레슨은 설치와 진행 순서를 공식 문서와 클론한 파일로 확인해 정리만 하며, 전역 설치는 이 PC에서 실행하지 않았습니다.

    3. 도구 상자 읽고 실행하기 (이전 단계와 독립)

      lab/lesson12/src/query.rs를 엽니다. TaskQuery::parse는 done=true&limit=2 같은 쿼리 문자열을 구조체로 바꾸고, 잘못된 값은 QueryError로 돌려줍니다. 실제 axum 핸들러에서는 Query<T> 추출기가 이 일을 대신하지만, 손으로 해 보면 추출기가 하는 일이 보입니다.

      impl TaskQuery {
    /// `done=true&limit=2&offset=1&q=책` 같은 쿼리 문자열을 해석합니다.
    pub fn parse(query: &str) -> Result<TaskQuery, QueryError> {
        let mut parsed = TaskQuery::default();
        for pair in query.split('&').filter(|pair| !pair.is_empty()) {
            let (key, value) = pair.split_once('=').unwrap_or((pair, ""));
            let invalid = || QueryError::InvalidValue {
                key: key.to_string(),
                value: value.to_string(),
            };
            match key {
                "done" => parsed.done = Some(value.parse().map_err(|_| invalid())?),
                "q" => parsed.search = Some(value.to_string()),
                "limit" => parsed.limit = Some(value.parse().map_err(|_| invalid())?),
                "offset" => parsed.offset = value.parse().map_err(|_| invalid())?,
                other => return Err(QueryError::UnknownKey(other.to_string())),
            }
        }
        Ok(parsed)
    }
}

      run_query는 필터와 검색을 먼저 적용하고, 남은 개수(total)를 센 뒤에 offset/limit으로 자릅니다. 순서가 중요합니다. total을 자른 뒤에 세면 "전체 몇 건"을 알 수 없습니다. 레슨 08에서 배운 filter·skip·take·collect가 그대로 쓰였습니다.

      /// 필터와 검색을 먼저 적용한 뒤, 남은 개수(total)를 세고 나서 offset/limit으로 자릅니다.
pub fn run_query(tasks: &[Task], query: &TaskQuery) -> Page<Task> {
    let matched: Vec<&Task> = tasks
        .iter()
        .filter(|task| query.done.is_none_or(|done| task.done == done))
        .filter(|task| {
            query
                .search
                .as_ref()
                .is_none_or(|word| task.title.contains(word.as_str()))
        })
        .collect();
    let total = matched.len();
    let items = matched
        .into_iter()
        .skip(query.offset)
        .take(query.limit.unwrap_or(usize::MAX))
        .cloned()
        .collect();
    Page { items, total }
}

    문제 1. 캡스톤 확장 A — 목록에 done 필터와 limit·offset 추가

    따라하기 2단계에서 만든 capstone의 GET /tasks에 쿼리 파라미터 세 개를 추가하세요. done(true면 완료한 Task만, false면 미완료만), limit(최대 개수), offset(건너뛸 개수)입니다. 모두 생략할 수 있고, 생략하면 done은 거르지 않고 offset은 0, limit은 제한 없음으로 동작합니다. 레슨 11에는 쿼리 파라미터가 없으므로 Query 추출기를 새로 가져오는 일부터 시작합니다. 테스트를 먼저 쓰고 실패하는 것을 본 뒤 구현하세요.

    완료 조건: 네 개의 Task(하나, 둘, 셋, 넷)를 만든 뒤 /tasks?limit=2&offset=1이 둘, 셋을, /tasks?offset=3이 하나를 돌려주고, /tasks?done=true가 완료한 Task만 돌려주고, cargo test -p capstone --test api가 기존 14개와 새 테스트를 포함해 모두 통과한다. 잘못된 값(/tasks?limit=abc)은 axum의 기본 거절 응답(JSON이 아닌 텍스트 400)이 나가는 것도 확인합니다.

    힌트 보기

    capstone/src/handlers.rs에 쿼리를 담을 구조체 ListParams를 만들고(Deserialize를 붙입니다) done: Option<bool>, limit: Option<usize>, offset: usize 필드를 두세요. 쿼리에 없을 때 offset이 0이 되려면 필드에 #[serde(default)]가 필요합니다. 핸들러에서는 레슨 08의 skip과 take를 쓰면 되고, limit이 없을 때는 unwrap_or(usize::MAX)가 편합니다. 테스트에서 첫 단계는 for title in [...]로 네 번 POST하는 것입니다.

    정답 예시 보기

    handlers.rs를 세 곳 고칩니다. 먼저 맨 위의 use axum::extract::{Path, State};를 use axum::extract::{Path, Query, State};로 바꾸고, use axum::http::{StatusCode, header}; 줄 아래에 use serde::Deserialize;를 추가합니다. 그리고 list_tasks 함수를 통째로 아래 코드(ListParams 구조체 포함)로 바꿉니다.

    #[derive(Debug, Deserialize)]
pub struct ListParams {
    done: Option<bool>,
    limit: Option<usize>,
    #[serde(default)]
    offset: usize,
}

pub async fn list_tasks(
    State(store): State<TaskStore>,
    Query(params): Query<ListParams>,
) -> Json<Vec<Task>> {
    let tasks = store
        .list()
        .into_iter()
        .filter(|task| params.done.is_none_or(|done| task.done == done))
        .skip(params.offset)
        .take(params.limit.unwrap_or(usize::MAX))
        .collect();
    Json(tasks)
}

    힌트 보기

    정답 예시 보기

    use std::fs;

use crate::codec::{decode_task, encode_task};

/// 과제 3 정답 예시: 줄 단위 텍스트 파일에 저장하는 저장소입니다.
/// id는 현재 파일에서 가장 큰 id + 1이라, 마지막 Task를 지운 뒤에는 id가 다시 쓰일 수 있습니다.
pub struct FileRepository {
    path: PathBuf,
}

impl FileRepository {
    pub fn open(path: impl Into<PathBuf>) -> Self {
        FileRepository { path: path.into() }
    }

    pub fn path(&self) -> &Path {
        &self.path
    }

    fn read_all(&self) -> Vec<Task> {
        match fs::read_to_string(&self.path) {
            Ok(text) => text
                .lines()
                .filter_map(|line| decode_task(line).ok())
                .collect(),
            Err(_) => Vec::new(),
        }
    }

    fn write_all(&self, tasks: &[Task]) {
        let mut text = String::new();
        for task in tasks {
            text.push_str(&encode_task(task));
            text.push('\n');
        }
        fs::write(&self.path, text).expect("파일에 쓸 수 없습니다");
    }
}

impl TaskRepository for FileRepository {
    fn list(&self) -> Vec<Task> {
        self.read_all()
    }

    fn insert(&mut self, title: &str) -> Task {
        let mut tasks = self.read_all();
        let id = tasks.iter().map(|task| task.id).max().unwrap_or(0) + 1;
        let task = Task {
            id,
            title: title.to_string(),
            done: false,
        };
        tasks.push(task.clone());
        self.write_all(&tasks);
        task
    }

    fn find(&self, id: u64) -> Option<Task> {
        self.read_all().into_iter().find(|task| task.id == id)
    }

    fn remove(&mut self, id: u64) -> bool {
        let mut tasks = self.read_all();
        let before = tasks.len();
        tasks.retain(|task| task.id != id);
        self.write_all(&tasks);
        tasks.len() < before
    }
}
