    핵심 개념 한국어 요약

    구조체(struct)는 이름 붙은 필드를 묶는 타입입니다. 데이터는 struct 블록에, 동작은 별도의 impl 블록에 적습니다. Kotlin 클래스처럼 한 덩어리가 아니라 데이터와 메서드가 분리돼 있습니다. 메서드의 첫 매개변수 &self(읽기), &mut self(수정), self(소유권을 가져감)로 이 메서드가 값을 어떻게 다루는지 시그니처에 드러납니다. self가 없는 함수는 연관 함수(associated function)이고 Rectangle::square(10)처럼 부릅니다. Kotlin의 companion object 팩토리 함수와 비슷합니다.

    열거형(enum)은 "여러 경우 중 하나"를 나타내는 타입이며, 각 경우(variant)가 서로 다른 데이터를 담을 수 있습니다. Add(String)은 문자열 하나를, Remove { id, force }는 이름 붙은 필드를 담습니다. Kotlin의 sealed class와 하위 data class 여러 개를 한 선언으로 쓰는 셈입니다. match는 enum의 모든 경우를 검사하는 분기이며, 빠진 경우가 있으면 컴파일이 안 됩니다(exhaustive 검사). 나중에 variant를 추가하면 처리하지 않은 모든 match가 컴파일 오류로 알려 주기 때문에 안전한 수정이 가능합니다.

    Rust에는 null이 없습니다. "값이 없을 수 있음"은 표준 라이브러리 enum인 Option<T>(Some(값) 또는 None)로 표현하고, 값을 꺼내려면 match나 if let으로 두 경우를 모두 다뤄야 합니다. let Some(n) = … else { … }(let-else)는 값이 있으면 변수에 꺼내고 없으면 일찍 빠져나가는 형태입니다. #[derive(Debug, Clone, PartialEq)]는 컴파일러에게 디버그 출력({:?}), 복제(clone), 비교(==) 코드를 자동으로 만들어 달라는 요청입니다. Kotlin의 data class가 toString, copy, equals를 공짜로 주는 것과 달리, Rust는 필요한 것만 하나씩 요청합니다.

      (앞 단계 없음) 탐색기(Ctrl+Shift+E)에서 lab/lesson05/src/bin에 my_structs.rs를 만들어 입력하고 실행합니다. 이 코드는 책의 직사각형 예제를 따른 것입니다.

      #[derive(Debug, Clone, PartialEq)]
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    fn square(size: u32) -> Rectangle {
        Rectangle {
            width: size,
            height: size,
        }
    }

    fn area(&self) -> u32 {
        self.width * self.height
    }

    fn can_hold(&self, other: &Rectangle) -> bool {
        self.width > other.width && self.height > other.height
    }

    fn grow(&mut self, amount: u32) {
        self.width += amount;
        self.height += amount;
    }
}

struct Meters(f64);

fn main() {
    let mut rect = Rectangle {
        width: 30,
        height: 50,
    };
    println!("{rect:?}");
    println!("넓이: {}", rect.area());

    let small = Rectangle::square(10);
    println!("rect가 small을 담을 수 있나? {}", rect.can_hold(&small));

    rect.grow(5);
    println!("키운 뒤: {rect:#?}");

    let wide = Rectangle {
        width: 100,
        ..rect.clone()
    };
    println!("너비만 바꾼 복사본: {wide:?}");
    println!("같은가? {}", wide == rect);

    let distance = Meters(12.5);
    println!("거리: {}m", distance.0);
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn area_multiplies_sides() {
        let rect = Rectangle {
            width: 3,
            height: 4,
        };
        assert_eq!(rect.area(), 12);
    }

    #[test]
    fn can_hold_needs_both_sides_larger() {
        let big = Rectangle::square(10);
        assert!(big.can_hold(&Rectangle::square(5)));
        assert!(!big.can_hold(&Rectangle::square(10)));
    }

    #[test]
    fn grow_changes_both_sides() {
        let mut rect = Rectangle::square(2);
        rect.grow(3);
        assert_eq!(rect, Rectangle::square(5));
    }
}

    2. 열거형과 match, Option 입력하기

      (1단계 이후) my_enums.rs를 만들어 입력하고 실행합니다. describe 함수의 match 팔(arm)이 순서대로 검사된다는 점, parse_number가 Option을 돌려준다는 점에 주목하세요. text.parse().ok()는 변환에 실패하면 None이 되는 형태입니다(Result는 레슨 06).

      #[derive(Debug)]
enum Command {
    Add(String),
    Done(u32),
    Remove { id: u32, force: bool },
    List,
}

fn describe(command: &Command) -> String {
    match command {
        Command::Add(title) => format!("추가: {title}"),
        Command::Done(id) => format!("완료 처리: #{id}"),
        Command::Remove { id: 0, .. } => String::from("0번은 지울 수 없습니다"),
        Command::Remove { id, force: true } => format!("강제 삭제: #{id}"),
        Command::Remove { id, force: false } => format!("삭제: #{id}"),
        Command::List => String::from("목록 보기"),
    }
}

fn parse_number(text: &str) -> Option<u32> {
    text.parse().ok()
}

fn main() {
    let commands = [
        Command::Add(String::from("우유 사기")),
        Command::Done(3),
        Command::Remove {
            id: 0,
            force: false,
        },
        Command::Remove { id: 4, force: true },
        Command::List,
    ];
    for command in &commands {
        println!("{}", describe(command));
    }

    let maybe = parse_number("42");
    match maybe {
        Some(n) => println!("숫자 {n}"),
        None => println!("숫자가 아님"),
    }

    if let Some(n) = parse_number("abc") {
        println!("파싱 성공: {n}");
    } else {
        println!("abc는 숫자가 아닙니다");
    }

    let Some(n) = parse_number("7") else {
        println!("여기에는 오지 않습니다");
        return;
    };
    println!("let-else로 꺼낸 값: {n}");

    println!("기본값 사용: {}", parse_number("x").unwrap_or(0));
}

#[cfg(test)]

        assert_eq!(parse_number("12"), Some(12));
        assert_eq!(parse_number("x"), None);
    }
}

    4. 여러 파일로 나뉜 코드 읽기

      (2단계와 별개, 이미 들어 있는 완성본) Ctrl+P를 눌러 lesson05/src/lib를 입력해 lab/lesson05/src/lib.rs를 열고 위에서 아래로 읽습니다. pub은 이 항목을 다른 파일(크레이트 밖)에서 쓸 수 있게 공개한다는 표시입니다(모듈과 공개 범위는 레슨 09). 이어서 lab/lesson05/src/bin/task_board.rs를 열어 use lesson05::{…} 줄이 라이브러리의 항목을 가져오는 것을 확인하고 실행합니다.

      #[derive(Debug, Clone, PartialEq)]
pub struct Task {
    pub id: u32,
    pub title: String,
    pub done: bool,
    pub priority: Priority,
}

impl Task {
    pub fn new(id: u32, title: &str, priority: Priority) -> Task {
        Task {
            id,
            title: title.to_string(),
            done: false,
            priority,
        }
    }

    pub fn complete(&mut self) {
        self.done = true;
    }

    pub fn summary(&self) -> String {
        let mark = if self.done { "x" } else { " " };
        format!("[{mark}] #{} {}", self.id, self.title)
    }
}

pub fn find_task(tasks: &[Task], id: u32) -> Option<&Task> {
    tasks.iter().find(|task| task.id == id)
}

pub fn first_pending(tasks: &[Task]) -> Option<&Task> {
    tasks.iter().find(|task| !task.done)
}
      use lesson05::{Priority, Task, find_task, first_pending};

fn main() {
    let mut tasks = vec![
        Task::new(1, "우유 사기", Priority::Low),
        Task::new(2, "보고서 쓰기", Priority::High),
        Task::new(3, "운동하기", Priority::Medium),
    ];

    for task in &tasks {
        println!("{} (우선순위 {})", task.summary(), task.priority.weight());
    }

    match find_task(&tasks, 2) {
        Some(task) => println!("찾음: {}", task.title),
        None => println!("2번 할 일이 없습니다"),
    }

    if let Some(task) = tasks.first_mut() {
        task.complete();
    }

    match first_pending(&tasks) {
        Some(task) => println!("다음에 할 일: {}", task.title),
        None => println!("모두 끝났습니다"),
    }

    let label = Priority::from_label("urgent");
    println!("urgent 라벨: {label:?}");
}

    use lesson05::{Priority, Task};

fn highest_pending(tasks: &[Task]) -> Option<&Task> {

            continue;
        }
        match best {
            Some(current) if current.priority.weight() >= task.priority.weight() => {}
            _ => best = Some(task),
        }
    }
    best
}
