    LESSON 04 · 컬렉션과 구조체

    슬라이스·맵·구조체·포인터

    슬라이스, 맵, 구조체와 메서드, 포인터를 직접 실행하며 Go에서 값이 복사되는 때와 공유되는 때를 구분합니다. 코드 사이를 오가는 VS Code 탐색 단축키(F12, F2 등)도 함께 익힙니다.

    • 소요 약 120분
    • 난이도 ★★★☆☆
    • 선행 레슨 03
    • 실습 폴더 lab/lesson04/mine (완성 코드: lab/lesson04)

    GOAL학습 목표

    • 슬라이스의 len, cap, append를 설명하고, 슬라이스를 잘라 쓸 때 원본과 메모리를 공유하는 것을 실행 결과로 확인할 수 있다.
    • 맵을 만들고 읽고 지우며, v, ok := m[k] 패턴과 nil 맵에 쓰면 패닉이 난다는 사실을 설명할 수 있다.
    • 구조체와 값 수신자·포인터 수신자 메서드를 작성하고, 값이 복사되는 경우와 원본이 바뀌는 경우를 구분할 수 있다.
    • for ... range가 요소의 복사본을 준다는 점을 알고, 요소를 바꾸려면 인덱스를 쓴다.
    • F12, Shift+F12, F2, Ctrl+Shift+O로 코드를 탐색하고 이름을 안전하게 바꿀 수 있다.

    핵심 개념 한국어 요약

    배열(array)과 슬라이스(slice). 배열은 크기가 타입에 포함되고([3]int) 대입하면 통째로 복사됩니다. 실무에서는 대부분 슬라이스를 씁니다. 슬라이스는 "배열 일부를 가리키는 창"으로, 내부적으로 (배열 위치, 길이 len, 용량 cap) 세 값을 가집니다. append는 용량이 모자라면 더 큰 배열을 새로 만들어 복사하므로 결과를 반드시 다시 대입해야 합니다(numbers = append(numbers, 4)). base[1:3]처럼 자른 슬라이스는 원본과 같은 배열을 공유합니다. 그래서 한쪽을 바꾸면 다른 쪽에도 보이고, 용량이 남아 있으면 append가 원본의 다음 칸을 덮어씁니다. 독립된 복사본이 필요하면 append([]int(nil), s...)나 slices.Clone을 씁니다. 초기화하지 않은 var s []int는 nil 슬라이스지만 길이가 0이고 append할 수 있습니다.

    맵(map). 해시 맵입니다. 없는 키를 읽으면 오류 대신 값 타입의 zero value가 나오므로, 키 존재 여부는 v, ok := m["k"]의 ok로 확인합니다. delete(m, k)로 지웁니다. nil 맵은 읽을 수 있지만 쓰면 패닉이 납니다. 순회 순서는 보장되지 않으므로, 정렬된 순서가 필요하면 키를 모아 정렬합니다(slices.Sorted(maps.Keys(m))).

    구조체(struct)와 메서드. 구조체는 필드를 묶은 값 타입입니다. 메서드는 클래스 안이 아니라 밖에서 func (t *Task) Toggle()처럼 수신자(receiver)를 앞에 적어 정의합니다. (t Task) 값 수신자는 복사본에서 일하므로 원본을 바꾸지 못하고, (t *Task) 포인터 수신자는 원본을 바꿉니다. 필드를 바꾸는 메서드는 포인터 수신자로 만듭니다. 구조체를 만드는 함수는 관례적으로 NewTask처럼 New로 시작합니다.

    포인터(pointer). &x는 변수의 주소, *p는 주소가 가리키는 값입니다. Go의 포인터에는 산술 연산이 없고, p.Field처럼 쓰면 자동으로 역참조됩니다. Kotlin에서 객체 변수가 항상 참조인 것과 달리 Go의 구조체 변수는 값 자체이고, 참조처럼 쓰고 싶을 때 *Task를 명시합니다.

    range의 복사. for _, t := range tasks의 t는 요소의 복사본입니다. 요소를 바꾸려면 tasks[i].Done = true처럼 인덱스로 접근합니다.

    1. 슬라이스 프로그램 입력하고 실행하기

      탐색기(Ctrl+Shift+E)에서 lab/lesson04 폴더를 우클릭해 새 폴더로 mine/slices를 만들고, 그 안에 새 파일 main.go를 만들어 아래 코드를 직접 입력합니다.

      package main

import "fmt"

func double(values []int) {
	for i := range values {
		values[i] *= 2
	}
}

func main() {
	numbers := []int{1, 2, 3}
	fmt.Println(numbers, len(numbers), cap(numbers))

	numbers = append(numbers, 4)
	fmt.Println(numbers, len(numbers), cap(numbers))

	base := []int{10, 20, 30, 40, 50}
	part := base[1:3]
	fmt.Println("part:", part, len(part), cap(part))

	part[0] = 99
	fmt.Println("base:", base)

	part = append(part, 77)
	fmt.Println("base:", base)

	independent := append([]int(nil), base[1:3]...)
	independent[0] = -1
	fmt.Println("복사본:", independent, "원본:", base)

	var empty []int
	fmt.Println("nil 슬라이스:", empty == nil, len(empty))
	empty = append(empty, 1)
	fmt.Println(empty)

	scores := []int{1, 2, 3}
	double(scores)
	fmt.Println("double 이후:", scores)

	array := [3]int{1, 2, 3}
	arrayCopy := array
	arrayCopy[0] = 100
	fmt.Println("배열:", array, arrayCopy)
}

    2. 출력으로 슬라이스의 동작 읽기

      1단계의 출력을 줄 단위로 해석합니다.

      • 2번째 줄: 용량 3인 슬라이스에 append하면 길이는 4, 용량은 6이 됩니다. 새 배열이 만들어졌다는 뜻입니다.
      • 3~5번째 줄: part := base[1:3]은 [20 30], 길이 2, 용량 4입니다(원본 배열의 인덱스 1부터 끝까지가 용량). part[0] = 99로 base도 바뀌었고, 용량이 남은 part에 append(part, 77)하자 base[3]이 40에서 77로 덮어써졌습니다.
      • 6번째 줄: append([]int(nil), base[1:3]...)로 만든 복사본은 원본과 독립이라 -1로 바꿔도 원본에 영향이 없습니다.
      • 7~8번째 줄: nil 슬라이스도 길이 0이고 append할 수 있습니다.
      • 9번째 줄: 슬라이스를 함수에 넘기면 요소가 공유되어 double이 원본 값을 바꿨습니다.
      • 10번째 줄: 배열은 대입하면 복사되어 arrayCopy만 바뀝니다.
    3. 맵 프로그램 입력하고 실행하기

      lab/lesson04/mine 아래에 maps 폴더와 main.go를 만들어 입력합니다. import 블록은 직접 쓰지 않아도 됩니다. slices.Sorted를 입력하고 저장하면 필요한 import가 자동으로 추가되는지 확인해 보세요(레슨 02의 저장 시 import 정리).

      package main

import (
	"fmt"
	"maps"
	"slices"
)

func main() {
	stock := map[string]int{"apple": 3, "pear": 0}
	stock["kiwi"] = 5
	fmt.Println(stock, len(stock))

	count, ok := stock["banana"]
	fmt.Println("banana:", count, ok)

	if count, ok := stock["apple"]; ok {
		fmt.Println("apple 재고:", count)
	}

	delete(stock, "pear")

	for _, name := range slices.Sorted(maps.Keys(stock)) {
		fmt.Println(name, stock[name])
	}

	tags := map[string][]string{}
	tags["go"] = append(tags["go"], "backend")
	tags["go"] = append(tags["go"], "cli")
	fmt.Println(tags)

	var missing map[string]int
	fmt.Println("nil 맵 읽기:", missing["x"], len(missing))
}

    4. 구조체와 메서드 프로그램 입력하고 실행하기

      structs 폴더와 main.go를 만들어 입력합니다. 이 파일을 이후 탐색 단계에서 계속 사용합니다. BrokenToggle은 일부러 만든 잘못된 메서드입니다.

      package main

import "fmt"

type Task struct {
	ID    int
	Title string
	Done  bool
}

func NewTask(id int, title string) *Task {
	return &Task{ID: id, Title: title}
}

func (t Task) Describe() string {
	mark := " "
	if t.Done {
		mark = "x"
	}
	return fmt.Sprintf("[%s] #%d %s", mark, t.ID, t.Title)
}

func (t *Task) Toggle() {
	t.Done = !t.Done
}

func (t Task) BrokenToggle() {
	t.Done = !t.Done
}

func main() {
	task := Task{ID: 1, Title: "Go 공부하기"}
	fmt.Println(task.Describe())
	fmt.Printf("%v\n%+v\n", task, task)

	task.BrokenToggle()
	fmt.Println("BrokenToggle 이후:", task.Done)

	task.Toggle()
	fmt.Println("Toggle 이후:", task.Done)

	copied := task
	copied.Title = "복사본"
	fmt.Println(task.Title, "/", copied.Title)

	pointer := &task
	pointer.Title = "포인터로 수정"
	fmt.Println(task.Title)

	created := NewTask(2, "테스트 작성")
	created.Toggle()
	fmt.Println(created.Describe())

	tasks := []Task{{ID: 3, Title: "배포하기"}, {ID: 4, Title: "회고하기"}}
	for _, t := range tasks {
		t.Done = true
	}
	fmt.Println("range 복사본을 바꾼 뒤:", tasks[0].Done, tasks[1].Done)

	for i := range tasks {
		tasks[i].Done = true
	}
	fmt.Println("인덱스로 바꾼 뒤:", tasks[0].Done, tasks[1].Done)

	var zero Task
	fmt.Printf("zero value: %+v\n", zero)
	fmt.Println(task == Task{ID: 1, Title: "포인터로 수정", Done: true})
}

      BrokenToggle 이후: false와 Toggle 이후: true의 차이가 값 수신자와 포인터 수신자의 차이입니다. BrokenToggle은 복사본의 Done을 바꿨기 때문에 원본이 그대로입니다. range 복사본을 바꾼 뒤: false false와 인덱스로 바꾼 뒤: true true도 같은 원리입니다. task.Toggle()처럼 변수에 포인터 메서드를 호출하면 Go가 (&task).Toggle()로 바꿔 줍니다.

    5. 정의로 이동, 미리 보기, 참조 찾기

      4단계의 mine/structs/main.go에서 main 함수 안의 task.Toggle()의 Toggle 위에 커서를 놓고 F12를 누릅니다. 커서가 func (t *Task) Toggle() 선언으로 이동합니다. Alt+←로 방금 있던 호출 위치로 돌아오고 Alt+→로 다시 앞으로 갑니다.

      이번에는 같은 Toggle 위에서 Alt+F12를 눌러 현재 위치를 떠나지 않고 정의를 작은 창으로 미리 봅니다(Esc 키로 닫습니다). 이어서 Task 구조체의 Done 필드 위에서 Shift+F12를 누르면 Done을 쓰는 모든 곳의 목록이 열립니다. 이 단계의 코드로 gopls가 찾은 참조는 선언 1곳과 사용 14곳, 모두 15곳입니다.

    6. 심볼 목록과 이름 바꾸기

      5단계에 이어 Ctrl+Shift+O를 누르면 현재 파일의 심볼(타입, 함수, 메서드, 필드) 목록이 열립니다. Toggle이라고 입력해 걸러 보세요. 목록에는 (*Task).Toggle처럼 수신자가 함께 보입니다. Esc 키로 닫고, Ctrl+T로 작업 영역 전체에서 심볼을 찾아 Toggle을 입력해 봅니다. 완성 코드와 내 코드 두 곳이 모두 나올 수 있습니다.

      이제 Task 구조체의 Done 필드 위에서 F2(이름 바꾸기)를 누르고 Completed를 입력한 뒤 엔터 키를 누릅니다. 이 파일 안의 Done이 모두 한 번에 바뀝니다(문자열 안의 글자는 바뀌지 않습니다). 저장(Ctrl+S)하면 필드 정렬이 gofmt 서식으로 정리됩니다. 다시 실행하면 출력 대부분은 4단계와 같지만, %+v로 필드 이름까지 찍는 3번째 줄과 11번째 줄은 Done 대신 Completed가 나옵니다. 필드 이름도 출력의 일부이기 때문입니다(아래 출력 참고). 확인한 뒤 같은 방법으로 Completed를 Done으로 되돌립니다. 이름만 바꾸는 단순 검색·바꾸기와 달리, F2는 코드의 의미를 이해하고 같은 필드만 바꿉니다.

	numbers := []int{1, 2, 3}

    문제 1. 단어 개수 세기

    문자열을 받아 단어별 등장 횟수를 맵으로 돌려주는 wordCount(text string) map[string]int를 작성하세요. 단어는 공백으로 나뉩니다. 이 문제는 A Tour of Go의 Maps 연습과 같습니다. 완료 조건: wordCount("I ate a donut. Then I ate another donut.")의 결과를 키 순서로 출력하면 I 2, Then 1, a 1, another 1, ate 2, donut. 2 여섯 줄이 나온다(대문자가 소문자보다 앞에 정렬됩니다).

    힌트 보기

    문자열을 공백 기준으로 자르는 함수가 strings.Fields입니다(import "strings"). 맵을 make(map[string]int)로 만들고 단어마다 counts[word]++를 합니다. 없는 키의 zero value가 0이라서 if로 확인하지 않아도 됩니다. 정렬해서 출력하려면 slices.Sorted(maps.Keys(counts))를 씁니다.

    정답 예시 보기 
    func wordCount(text string) map[string]int {
	counts := make(map[string]int)
	for _, word := range strings.Fields(text) {
		counts[word]++
	}
	return counts
}

    문제 2. 남은 일 모으기와 모두 완료하기

    아래 Task를 이용해, 완료하지 않은 일의 제목만 모아 돌려주는 pendingTitles(tasks []Task) []string과, 슬라이스의 모든 일을 완료로 바꾸는 completeAll(tasks []Task)를 작성하세요. 완료 조건: completeAll을 호출한 뒤 pendingTitles가 빈 슬라이스를 돌려주고, 호출한 쪽의 슬라이스가 실제로 바뀐다.

    type Task struct {
	ID    int
	Title string
	Done  bool
}
    힌트 보기

    for _, task := range tasks로 task.Done = true를 하면 복사본만 바뀝니다. completeAll은 for i := range tasks와 tasks[i].Done = true를 써야 합니다. pendingTitles는 var titles []string으로 시작해 append하고 마지막에 돌려줍니다. 비어 있으면 nil 슬라이스를 돌려줘도 길이는 0이므로 괜찮습니다.

    정답 예시 보기 
    func pendingTitles(tasks []Task) []string {
	var titles []string
	for _, task := range tasks {
		if !task.Done {
			titles = append(titles, task.Title)
		}
	}
	return titles
}

func completeAll(tasks []Task) {
	for i := range tasks {
		tasks[i].Done = true
	}
}
